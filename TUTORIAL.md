## 2. Os modelos do AG (os "cérebros")

No Antigravity você escolhe qual inteligência artificial vai trabalhar. Fica num menu perto da caixa onde você escreve. Os nomes mudam com o tempo (peça ao agente: "quais modelos eu tenho hoje e qual você recomenda para isto?"), mas a lógica é sempre esta:

| Tipo | Como reconhecer no menu | Quando usar |
|---|---|---|
| ⚡ **Rápido** | nomes com **Flash** (Gemini Flash) | Perguntas simples, textos curtos, legenda, revisar ortografia, pequenas mudanças. Gasta pouco. |
| 🧠 **Pensa mais** | nomes com **Pro** (Gemini Pro), ou "High" | Slides de aula, artes, editar vídeo, qualquer coisa com várias etapas. É o padrão bom para o dia a dia do kit. |
| ✍️ **Claude** | **Claude Sonnet** | Muito bom para escrever bonito e para mexer em código. Boa segunda opção quando o Pro se enrolar. |
| 🏋️ **O mais forte** | **Claude Opus** (ou o maior da lista) | Tarefas difíceis que os outros não resolveram. Gasta mais da sua cota. |

**Modos de conversa:**
- **Planning (planejar):** o agente pensa e mostra um plano antes de fazer. Use para coisas grandes (aula inteira, vídeo).
- **Fast (rápido):** faz direto. Use para coisas pequenas.

**Cota:** cada modelo tem um limite de uso que se renova de tempos em tempos. Se aparecer aviso de limite, troque de modelo ou espere um pouco. Não é erro seu.

## 3. Como pedir bem (receitas do dia a dia)

1. **Uma coisa por vez.** "Faz o post" → olha → "agora muda a cor" → olha.
2. **Diga para quem é e onde vai.** "Post para o Instagram da Gatoteca, quadrado" ou "Slides para alunos chilenos, nível iniciante, 50 minutos".
3. **Mande o material.** Arraste para a conversa o vídeo, a foto ou o PDF do livro.
4. **Peça para ver.** "Me mostra antes de terminar."
5. **Corrija com calma.** "Gostei, mas o texto está pequeno" funciona melhor do que começar de novo.
6. **Quando der erro**, escreva só: "deu erro, resolve para mim". O agente lê o erro e conserta.

**Receitas prontas para copiar:**
- 🐈 "Faz um post de divulgação da Gatoteca: gratuito, a cada quinze dias, no Recife. Pouco texto e chamativo."
- 📊 "Faz os slides da aula sobre [tema] para [alunos], com 3 atividades e gabarito nas notas. Me mostra a prévia."
- 🎬 "Edita este vídeo no estilo Iara. Primeiro me mostra o corte para eu aprovar."
- 🔎 "Pesquisa para mim [pergunta] e me responde com as fontes."
- 🧰 "Existe alguma ferramenta pronta para [coisa]? Pesquisa no GitHub antes de criar."
- 🔄 "Atualiza o kit da Gatoteca (git pull) e roda o instalador de novo."

## 4. Onde ficam as coisas

Tudo fica na pasta do kit (`gatoteca-e-edicao-iara`), que o agente sabe achar. Os trabalhos prontos ficam numa pasta que ele te diz no fim de cada pedido. Se perder algo, pergunte: "onde ficou o último post que você fez?".

Seus vídeos e fotos originais nunca são alterados: o agente sempre trabalha numa cópia.
